# Pinned timezone names

`tzdb2025b.json` contains the sorted, exact `Zone` names and `Link` aliases
from IANA tzdb 2025b's africa, antarctica, asia, australasia, europe,
northamerica, southamerica, etcetera, factory, and backward files (the upstream default TDATA). No clock offsets are
used. Aliases are preserved; host timezone data is never consulted.

Source: https://data.iana.org/time-zones/releases/tzdata2025b.tar.gz

Archive SHA-256: `11810413345fc7805017e27ea9fa4885fd74cd61b2911711ad038f5d28d71474`.

The IANA timezone data is public domain. Refreshing this catalog is an explicit
configuration change; it must not change retained operation results or stored facts.
